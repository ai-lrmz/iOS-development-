# FavouriteList 🎬

An iOS application built with UIKit and Swift.

## About the App

FavouriteList displays my 20 favorite Korean dramas
and Turkish TV series.

Each series includes:
- Poster image
- Russian title
- Genre and country
- Rating from 0 to 5 stars

## Technologies

- Swift
- UIKit
- UITableView
- Custom UITableViewCell
- Auto Layout
- Storyboard
- SF Symbols
