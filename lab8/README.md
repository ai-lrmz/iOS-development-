#  🎶 Music Player - Lab8

**Project Description**

Music Player is an iOS application developed using Swift, UIKit, and Xcode.

The application allows users to play, pause, and switch between 10 audio tracks.

Features
- Play and pause music
- Next and previous track controls
- Display song title and artist
- Display album cover images
- Automatically play the next track
- Loop through the playlist
- Adaptive layout using UIStrackView and Auto Layout

#### Technologies Used
- Swift
- UIKit
- AVFoundation
- AVAudioPlayer
- UIStackView
- Auto Layout
- Xcode

2. Select an iPhone simulator.
3. Press Command + R to build and run the application.
