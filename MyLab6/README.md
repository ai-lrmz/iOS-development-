Lab 6 – Favorites Roulette

Dorama Roulette

This is an iOS application developed using Swift and Storyboard in Xcode.

The app displays my 10 favorite Korean dramas. When the user taps the Spin Roulette button, a random drama appears with its poster, title, and description.
